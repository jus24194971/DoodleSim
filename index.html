🚀 Quick start — two ways to begin

I know what I need to accomplish

  1. Click 🎯 Plan Advisor
  2. Describe the mission: what talks to what, how far, how much data
  3. Review the ranked configurations and hit Apply to map
  4. The design lands on the map, aimed and cabled — verify it over your real deployment terrain

I want to build it myself

  1. + Add Node, then click the map to place each radio
  2. Configure each node in the sidebar (radio, band, antenna, height…)
  3. ⟋ Link Nodes, then click two nodes to analyze the path
  4. Click any link (on the map or sidebar) to open its terrain profile

📡 Configuring a node

Each node is a full radio install. The fields that matter most:

  • Platform — sets a realistic default height: mast 10 m, UAV 100 m, UGV 1 m, vessel 4 m, handheld 1.5 m. Height drives the terrain math, so keep it honest.
  • Radio & band — all current Mesh Rider models with their real per-MCS transmit power and sensitivity (the same conservative numbers as the official Doodle Labs estimator). Both ends of a link must share a band to talk.
  • Antenna — pick from the catalog (★ = Doodle Labs recommended; the rest are datasheet-verified third-party models) or enter a custom gain + beamwidth. Directional antennas get a beam wedge on the map.
  • Cable — choose MC400/MC600-class and a length; loss is computed automatically for the operating frequency (and updates if you change bands). Use "Manual" to type a known loss.
  • BDA gain — add amplification (e.g. Mesh Rider Boost, Triad) as extra dB in the budget.

🎯 Aiming directional antennas

Sectors, dishes, yagis and panels show a blue beam wedge covering their real beamwidth. Drag the white handle at the wedge tip to aim — links and heatmaps recompute on release. Off-boresight targets pay a pattern penalty in both azimuth and elevation: a high-gain omni has a narrow vertical beam and will genuinely lose a drone directly overhead, and the Tilt field matters when serving targets far above or below you.

🗺 Reading the map

  • Green link — clear line of sight with a healthy margin
  • Amber link — Fresnel-zone intrusion: it may work, expect degradation in rain/multipath
  • Orange link — terrain blocks the direct ray; running on diffraction
  • Red link — the budget doesn't close at any data rate

Every link label shows distance, the best usable MCS, and expected throughput. Click a link for the terrain profile: ground elevation with earth curvature, the line-of-sight ray, the Fresnel ellipse, and the worst obstruction marked.

▦ Coverage heatmaps

On any node card, set the remote end's height and gain (what does a 2 m handheld see? a 100 m drone?) and click Coverage heatmap. The map colors everywhere that node can serve, by achievable MCS/throughput — computed over real terrain in every direction, honoring the antenna's beam shape. Recompute after aiming or config changes; run it per-scenario by changing the remote height.

🧭 Extending existing infrastructure

Already have sites deployed (or saved)? In the Plan Advisor choose Extend existing infrastructure: pick your anchor node, pick the target on the map, and say what platform needs service. The advisor evaluates the true terrain path using your node's actual configuration — including how it's currently aimed — and recommends the least-change fix: a remote kit alone if it works, a re-aim, a taller mast, amplification, or a relay site it locates along the profile (with coordinates and mast height) when a single hop can't close. Every option includes a full install spec: boresight bearing, heights, cable class and length.

📄 Deliverables

  • 💾 Save / 📂 Load — layouts save as portable .json files (one per customer engagement); the browser also auto-saves as you work.
  • 📄 Report — exports a customer-ready design document: objective, deployment map, equipment & placement table, per-link terrain analysis with profile charts, and minimum UAV altitudes for Fresnel clearance. Opens anywhere, prints to PDF.

🔬 The math (and its honesty)

Link budgets use the official Doodle Labs methodology — conservative per-MCS sensitivities and transmit powers matching the Doodle Labs Range Estimation Tool exactly, with a 10 dB fade margin. On top of that, this tool adds what a distance-only calculator can't: real elevation profiles (30 m SRTM data), 4/3-earth curvature, the 60% first-Fresnel-zone clearance criterion, ITU-R P.526 knife-edge diffraction, antenna radiation patterns, and frequency-dependent cable loss. Predictions are planning-grade: field-verify critical links, and remember interference, vegetation, and installation quality are not modeled.

💡 Tips

  • Rename nodes (click the name) before exporting — customers see those labels.
  • Keyboard: N = add node, L = link mode.
  • Drag nodes to explore placement — everything recomputes live.
  • Narrower channels (3/5 MHz) buy several dB of sensitivity: when range beats throughput, narrow the channel.
  • For vessels and UGVs, small height changes matter enormously — the first few meters clear the worst of the Fresnel zone.
